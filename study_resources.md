## MIT OpenCourseWare — Topic Map

> MIT OCW courses are free. Most use R or are language-agnostic (theory).  
> Use these to supplement your primary resources above — especially for video lectures and rigorous problem sets.

### Best-Match Courses

| Course | Materials | Language | Link |
|--------|-----------|----------|------|
| **18.05 — Intro to Probability & Statistics (Spring 2022)** | Lecture notes, 11 problem sets w/ solutions, exams w/ solutions, **R tutorials & R code** | **R** | [ocw.mit.edu](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/) |
| **18.443 — Statistics for Applications (Spring 2015)** | 17 lecture notes, problem sets w/ solutions, **R scripts**, exams | **R** | [ocw.mit.edu](https://ocw.mit.edu/courses/18-443-statistics-for-applications-spring-2015/) |
| **18.650 — Statistics for Applications (Fall 2016)** | **24 video lectures**, lecture slides, problem sets | Theory | [ocw.mit.edu](https://ocw.mit.edu/courses/18-650-statistics-for-applications-fall-2016/) |
| **6.041SC — Probabilistic Systems Analysis (Fall 2013)** | **25 video lectures + 51 help videos**, problem sets w/ solutions, exams w/ solutions | Theory | [ocw.mit.edu](https://ocw.mit.edu/courses/6-041sc-probabilistic-systems-analysis-and-applied-probability-fall-2013/) |

### What to Use from Each Course

| STAT 2150 Topic | Primary MIT Resource | What to Use |
|-----------------|---------------------|-------------|
| 1. EDA | 18.443 L12–L13 | Lecture notes on summarizing data & dynamic graphics |
| 2. R Programming | **18.05 R Tutorials** | Tutorials on R basics, functions, for loops, plotting, random numbers |
| 3. RVs & Distributions | **6.041SC Lec 5–14** ⭐ | Video lectures: discrete RVs (Binomial, Poisson), continuous RVs (Uniform, Normal, Exponential), joint distributions, CLT |
| 4. Estimation | **18.650 Lec 3–6** ⭐ | Video lectures: parametric inference, MLE, method of moments |
| 5. Hypothesis Testing | **18.650 Lec 7–12** ⭐ | Video lectures: parametric testing, goodness-of-fit |
| 6. Simulation & Resampling | **18.05 Class 24, Studios 8 & 10** | R code for empirical & parametric bootstrap, simulation of NHST |
| 6. Resampling (theory) | 18.443 L6 | Bootstrap confidence intervals — rigorous treatment |
| 7. Regression | **18.650 Lec 13–16** ⭐ | Video lectures: regression (4 full lectures) |
| 7. ANOVA | 18.443 L16 | Comparing independent samples and ANOVA |
| 8. R Markdown | *No MIT coverage* | Use Posit docs instead |

> ⭐ = Has video lectures — best for self-study when you need to "watch and learn."

### Key Notes
- **18.05** is the only MIT course that uses R and covers bootstrap with R code — closest to STAT 2150
- **18.443** mirrors the STAT 2150 syllabus almost exactly (MoM → MLE → bootstrap → testing → EDA → regression → ANOVA)
- **6.041SC + 18.650** together provide full video coverage of Topics 3–5 and 7
- **18.655** (Mathematical Statistics) exists but is graduate-level — skip unless you want deep theory
